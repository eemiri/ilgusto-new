## Overview

**Page Purpose:** Wärme + Vertrauen aufbauen. Die Story-Section beantwortet "Wer steht dahinter und warum lohnt sich die Fahrt?" — **Narrativ: Eine Familie, die in nur 2 Jahren zum bestbewerteten Italiener der Region wurde (4,9★, 144 Gäste).** Familienbetrieb + Achievement als emotionaler Kern (nicht das übliche Jahrhunderte-Erbe — die junge, ehrliche Erfolgsgeschichte). Social Proof als Bestätigung eingewoben, nicht als Badge.

**User Situation:** Anna hat den Hero gesehen, scrollt weiter. Bevor sie das Menü prüft, will sie ein Gefühl für das Restaurant — ist das echt, ist das besonders?

**Success Criteria:** Anna fühlt Vertrauen & Wärme und scrollt überzeugt zur Speisekarte. Die "2 Jahre / 4,9★"-Geschichte verankert den Premium-Anspruch.

**Entry Points:**
- Scroll von #hero
- Nav-Klick (falls "Über uns" in Nav aufgenommen — siehe Open Question #3)

**Exit Points:**
- Scroll → #menu (Speisekarte)

## Layout Structure

Zweispaltig auf Desktop (Interior-Foto + Text), einspaltig gestapelt auf Mobile. Ein kleiner floating Teller setzt einen Akzent (Leitmotiv, **Bild = Interior-Foto + Teller kombiniert**). Großzügiger Whitespace — "warm, unhurried".

```
+------------------------------------------+
| (kein eigener Nav-Block — geteilte Nav)  |
+------------------------------------------+
|                                          |
|  [Eyebrow: Über uns]                     |
|                                          |
|  ┌───────────────┐   [Headline: 2 Jahre,│
|  │ Interior-Foto │    eine klare Nr. 1]  │
|  │ (Ambiente)    │   🍝 ← floating Teller│
|  │            ╭──┘    (kleiner Akzent)   │
|  └────────────┤🍝│                        │
|               ╰──╯   [Story-Text-Block]  │
|                      [Stat-Zeile: 4,9★ · │
|                       144 · #1 · 2 Jahre]│
+------------------------------------------+
```

**Layout-Prinzip:** Foto links/oben für Atmosphäre, Text rechts/darunter. Floating Teller überlappt dezent Foto-Kante als verbindendes Element. Stat-Zeile verankert das "2 Jahre, 4,9★"-Narrativ als Fließtext, nicht als Badge-Grid.

## Technical Notes

- **Bild-Asset:** Interior-Foto aus den 4 vorhandenen Ambiente-Shots; ggf. leicht warm getönt/abgedunkelt für Palette-Konsistenz. Floating Teller separat als freigestelltes PNG.
- **Stat-Zeile:** Statisch hartcodiert (4,9★ / 144 / #1 / 2 Jahre). Bei Aktualisierung manuell pflegen (kein Live-Feed).
- **Sprache:** `data-de`/`data-fr` + `setLang()`, konsistent mit anderen Sections.
- **Position im Scroll:** #about zwischen #hero und #menu. Falls "Über uns" nicht in der Haupt-Nav steht (Nav hat aktuell Speisekarte · Galerie · Reservieren), bleibt die Section reiner Scroll-Inhalt.
