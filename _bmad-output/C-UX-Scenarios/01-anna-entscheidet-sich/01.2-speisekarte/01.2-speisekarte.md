## Overview

**Page Purpose:** Anna bestätigt: Il Gusto ist leistbar UND hochwertig. Menü und Preise validieren die Wahl für Date-Night — ohne Reizüberflutung, mit eleganter Übersicht. Ein floating Overhead-Teller führt das visuelle Leitmotiv aus dem Hero fort.

**User Situation:** Anna hat den Hero gesehen (4,9★ + Essen + Tagline), ist neugierig und scrollt weiter. Sie will jetzt wissen: Was gibt es, und passt es ins Budget? Sie scannt, sie liest nicht.

**Success Criteria:** Anna findet schnell die Kategorie die sie interessiert (z.B. Pasta), sieht Preise im erwarteten Rahmen (€17–38), und scrollt überzeugt weiter zur Reservierung.

**Entry Points:**
- Scroll von #hero (Über uns dazwischen im Full-Scroll)
- Nav-Klick "Speisekarte" / "Carte" → smooth-scroll zu #menu
- Direktlink mit Anchor `#menu`

**Exit Points:**
- Scroll → #gallery (Galerie) bzw. #reservation
- Nav-Klick → #reservation (Reservieren)

## Layout Structure

Einspaltige, zentrierte Spalte (max-width 900px). Akkordeon-Kategorien gestapelt — Klick auf eine Kategorie zeigt ihre Gerichtliste. Ruhig, viel Luft. Ein floating Overhead-Teller (Plate-Placement **Option B** — gestreut) begleitet die Section und führt das Hero-Leitmotiv fort.

```
+------------------------------------------+
| NAV (sticky, geteilt mit Hero)           |
+------------------------------------------+
|                              ╭───────╮   |
|   [Eyebrow: Unsere Küche]    │ 🍝    │   |  ← floating Teller
|   [Title: Speisekarte]       ╰───────╯   |     (Option B, dezent)
|                                          |
|   ╭────────────────────────────────╮    |
|   │ VORSPEISEN   ab 14,50 €   6  + │    |  ← cat-header (klickbar)
|   ╰────────────────────────────────╯    |
|   ╭────────────────────────────────╮    |
|   │ HAUSGEM. PASTA  ab 17,90 €  3 + │    |  ← alle starten geschlossen
|   ╰────────────────────────────────╯    |
|   ╭ HAUPTSPEISEN  ab 26,90 €   8  + ╮    |
|   ╭ DESSERT       ab 7,90 €    6  + ╮    |
|                                          |
|   ┌ Tageskarte-Hinweis ───────────┐     |
+------------------------------------------+
```

**Layout-Prinzip:** Akkordeon — alle Kategorien starten **geschlossen**, Mehrfach-Offen erlaubt (siehe Interaktionen). Auf Mobile identische Struktur, reduziertes horizontales Padding; floating Teller kleiner/dezenter oder oberhalb des Headers.

## Page States

| State | Wann | Appearance | Actions |
|-------|------|------------|---------|
| **Default — alle zu** | Initial bei Section-Eintritt | **Alle Kategorien geschlossen** ("+"), nur Header + Range + Count sichtbar. Maximales Whitespace, Anna scannt selbst. | Kategorie antippen, scrollen |
| **Kategorie offen** | User tippt cat-header | Body expandiert (max-height 0→1000px, 0.5s cubic-bezier), Toggle rotiert zu "×", Gold | Andere öffnen, schließen, anrufen |
| **Default (FR)** | Sprach-Toggle FR | Alle Namen, Ranges, Counts, Beschreibungen auf Französisch | wie Default |
| **Scroll-Reveal** | Section betritt Viewport | Header + floating Teller + Kategorien faden gestaffelt ein (optional, siehe Technical Notes) | — |

**Startzustand — ENTSCHIEDEN:** Alle Kategorien starten **geschlossen** (ruhiger Überblick, Whitespace = Luxus). Anna öffnet selbst, was sie interessiert.

## Technical Notes

- **Akkordeon:** `max-height` Transition (0 → 1000px, `cubic-bezier(0.4,0,0.2,1)`, 0.5s). Toggle via `.category.open` Klasse. Für >1000px hohe Kategorien (volle Hauptspeisen-Liste) `max-height` erhöhen oder JS-gemessene Höhe nutzen.
- **Sprach-Toggle:** Geteiltes System mit Hero — `data-de` / `data-fr` Attribute, `setLang()` ersetzt `textContent`. localStorage key `ilgusto-lang`.
- **Accessibility:** `cat-header` als `<button>` mit `aria-expanded`, `cat-body` mit `aria-hidden`. Fokus-Stil sichtbar. Toggle-Icon rein dekorativ (`aria-hidden`).
- **SEO:** Alle Gerichte als semantisches HTML rendern — auch in geschlossenen Kategorien im DOM vorhanden (nur visuell collapsed), damit crawlbar.
- **Preise:** Hartcodiert im HTML (statische Seite, kein CMS). Format "18,90 €" (deutsches Dezimalkomma, € nachgestellt).
