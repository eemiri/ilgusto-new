## Overview

**Page Purpose:** Den Gast konvertieren — Tisch reservieren. Primär über das eingebettete **resmio**-Buchungswidget (24/7, ohne Anruf), sekundär per Telefon. Öffnungszeiten + Gruppen-Anlass-Hinweis bestätigen die Machbarkeit.

**User Situation:** Anna ist überzeugt (Hero + Speisekarte). Sie will jetzt handeln. Sie ist auf Mobile, hat wenig Zeit — der Weg zur Reservierung muss reibungslos sein.

**Success Criteria:** Anna schließt eine Reservierung ab — entweder im resmio-Widget (Datum/Zeit/Personen gewählt, bestätigt) oder per Tap auf die Telefonnummer.

**Entry Points:**
- Scroll von #menu (bzw. #gallery)
- Nav-Klick "Reservieren" / "Réserver" → smooth-scroll zu #reservation
- **"Reserve with Google"** (Google Business Profil → resmio) — externer Einstieg direkt in die Buchung
- Hero Telefon-CTA (alternativer Direktweg)

**Exit Points:**
- Reservierung abgeschlossen (resmio-Bestätigung) ✓
- `tel:+4968059439490` gewählt ✓
- E-Mail an `mail@ilgusto-sb.de` (Gruppen-Anfragen)

## Technical Notes

- **resmio Embed:** Embed-Code stammt aus dem resmio-Konto des Restaurants. Native Integration bevorzugt (Gast bleibt auf der Seite). Design-Anpassung (Farben/Schrift) erfolgt **im resmio-Backend** — erfordert Konto-Zugang (siehe Open Question #1).
- **DSGVO/Consent:** resmio-Widget lädt von externer Domain (app.resmio.com). Prüfen, ob Consent-Banner/Two-Click-Lösung nötig ist, bevor das iframe lädt. Relevant für deutschen Markt.
- **Reserve with Google:** Google Business Profil sollte auf dieselbe resmio-Quelle zeigen — konsistente Buchungslogik über alle Einstiegspunkte.
- **Telefon:** `tel:`-Link funktioniert mobil direkt; Desktop zeigt Nummer zum Abtippen.
- **Schema.org:** `Restaurant` + `openingHours` + `telephone` + `address` für SEO/Rich Results.
- **Sprache:** resmio-Widget-Locale an Seiten-Sprache (DE/FR) koppeln, falls von resmio unterstützt.
