## Overview

**Page Purpose:** Visuelle Überzeugung durch Food-Fotografie — Marco erkennt in Sekunden: Das Handwerk ist real, das ist kein Pizzarestaurant. Die kreisförmigen Overhead-Teller sind das Herzstück des visuellen Systems; der Plate-Reveal (Clip-Path Circle Expand) macht jeden Teller zum Erlebnis.

**User Situation:** Marco hat im Hero 4,9★ + Tagline gesehen, ist neugierig und scrollt gezielt zur Galerie für den visuellen Beweis. Mobile, Freitagnachmittag, sucht das besondere Abendessen.

**Success Criteria:** Marco ist überzeugt — er klickt mindestens einen Teller auf (sieht Plating-Detail), und folgt dem CTA zur Reservierung.

**Entry Points:**
- Scroll von #hero (02.1)
- Nav-Klick "Galerie" / "Galerie" → smooth-scroll zu #gallery

**Exit Points:**
- CTA "Tisch reservieren" → smooth-scroll zu #reservation (resmio)
- Nav-Klick → #reservation

## Layout Structure

Asymmetrisches, editoriales Layout — kein Grid. Kreisförmige Teller floaten frei auf dem warmen Dunkel (`#141210`), unterschiedliche Größen & vertikale Offsets erzeugen Rhythmus. Teller sind **nackt** (kein Text) bis zum Klick. Klick → Clip-Path-Kreis expandiert vom Teller-Mittelpunkt zum Vollbild-Reveal.

```
+------------------------------------------+
| NAV (sticky — versteckt sich im Reveal)  |
+------------------------------------------+
|                                          |
|  [g-label: Unsere Küche — anklicken]     |
|                                          |
|     🍝          🥩                        |  ← varied sizes,
|         🍝                                |     vertical offsets,
|     🍃          🍝                        |     flex-wrap asymmetrisch
|              🍰                           |
|                                          |
|        [ Tisch reservieren → ]           |  ← CTA zu #reservation
+------------------------------------------+

  ── Klick auf Teller ──>  REVEAL:
+------------------------------------------+
|   ╭─────────╮   VORSPEISE                 |
|   │ großer  │   Carpaccio di Manzo        |
|   │ Teller  │   Rinderfilet · Parmesan…   |
|   ╰─────────╯   € 21,50                    |
|                 ← zurück                   |
+------------------------------------------+
   (clip-path circle expand vom Teller-Zentrum)
```

**Layout-Prinzip:** `display: flex; flex-wrap: wrap; align-items: flex-end` mit Gap 44px/52px; einzelne Teller mit `margin-top`/`margin-bottom`-Offsets für Asymmetrie. Mobile: Teller groß, gestapelt, viel Luft.

### Section: Plate Reveal (Overlay-Interaktion) — LOCKED

**OBJECT ID:** `gal-reveal`

| Property | Value |
|----------|-------|
| Technik | **Clip-Path Circle Expand** (Brief LOCKED). Referenz: Balans Kitchen |
| Layer | `position: fixed; inset: 0`, Hintergrund `#1a1612` (gleicher warmer Dunkelton — kein harter Kontrastwechsel) |
| Öffnen | `clip-path: circle(0px at [Teller-Cx] [Teller-Cy])` → `circle(200vmax at …)`, 0.85s `cubic-bezier(0.76,0,0.24,1)` |
| Ursprung | Exakter Teller-Mittelpunkt (via `getBoundingClientRect`) |
| Großer Teller | Links (~7% vw), Größe `min(36vw, 58vh, 360px)`, fade+scale-in (delay 0.3s) |
| Text | Rechts daneben: Kategorie · Name · Beschreibung · Preis · "← zurück", translateY-fade (delay 0.58s) |
| Schließen | "← zurück" oder **ESC** → Kreis zieht sich zurück an Ursprung, 0.72s; Nav/Hero/Gallery faden wieder ein |
| Kein Modal | Kein Overlay-Rechteck, kein Dimmer — der Teller-Kreis IST die Maske |
| Sperre | Nur ein Reveal gleichzeitig (`isOpen`-Guard) |

## Technical Notes

- **Clip-Path Performance:** `clip-path: circle()` animiert — auf `transform`/`clip-path` beschränkt halten (GPU). `200vmax` Radius garantiert Vollabdeckung auf allen Viewports.
- **Ursprungsberechnung:** `getBoundingClientRect()` beim Klick → Kreismittelpunkt = Teller-Zentrum. Bei Resize während offenem Reveal: schließen oder neu berechnen.
- **Freigestellte Teller:** PNG mit transparentem Hintergrund. Bis neue Fotos da sind: Archiv-Overheads freistellen oder Platzhalter-Gradient (wie Demo).
- **Sprache:** Reveal-Texte aus `data-[de|fr]`-Attributen; `setLang()` aktualisiert. localStorage `ilgusto-lang`.
- **Accessibility:** Reveal ist eine Custom-Interaktion — sicherstellen: Tastatur-bedienbar (Enter öffnet, ESC schließt), `aria-modal`/Fokus im offenen Zustand, sichtbarer Fokus-Ring.
- **Reduced Motion:** Bei `prefers-reduced-motion` Clip-Path-Animation verkürzen/ersetzen durch sanftes Fade.
